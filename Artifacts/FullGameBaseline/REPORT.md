- Unity 6000.0.57f1, Windows x64. Полный Release-билд со всеми включёнными сценами: `Builds/Windows/RogueDrive_Survival.exe`, успешен, 697 МБ по отчёту Unity (`build.log`). Это проверка сборки, не приёмка всей кампании.
- Добавлена отдельная Development-сборка `Builds/FullGameDev/RogueDrive.exe` для двухпроцессных тестов. Сборка успешна, 0 ошибок, 120 предупреждений (`development-build.log`). Среди предупреждений есть превышение глубины сериализации `WorkshopPartData.internals`; перед релизом нужно исправить и проверить сохранение вложенных деталей.
- Прежний интерактивный Unity Editor аварийно завершился до начала этой проверки из-за нехватки выделяемой памяти. Обе пакетные сборки после этого прошли. Причина прежней нехватки памяти не устранена, профилирование игры и Editor остаётся открытым.

## Исправленный сетевой дефект

В `CoopPlayer` патроны раньше списывались только у клиента, а сервер принимал выстрел по таймеру без проверки магазина. Теперь текущий магазин, запас и состояние перезарядки — серверные `NetworkVariable`; сервер проверяет и списывает каждый выстрел, сам завершает перезарядку и выдаёт найденные патроны. Клиентский HUD читает реплицированное состояние. Это закрывает одну часть серверной проверки боя, но общий лут и сохранение кооператива ещё не готовы.

## Следующий критический блок

Сетевой тайник пока вызывает одиночный `RoadsideScavengePoint.Interact` на хосте. Это меняет одиночные singleton-инвентари, а найденные предметы и опустошение тайника не реплицируются как общее состояние. Следующая задача — стабильные ID тайников/предметов, серверная транзакция подбора и багажник, поздний вход и защита от двух одновременных запросов. Затем подключить к этой модели обслуживание на СТО. Обычный полный проезд четырёх регионов и тест на двух физических ПК остаются открытыми.
