# Логика переносимых предметов

Мелкие предметы остаются в слотах. Активный предмет используется клавишей F; R меняет батарейку у выбранного фонаря или рации. Инструменты для монтажа достаточно иметь в рюкзаке или быстрых слотах.

| Предмет | Функция |
|---|---|
| Фонарик | F включает свет. Полная батарейка рассчитана на 5 минут. R расходует одну батарейку из инвентаря. Убранный фонарь выключается, заряд сохраняется. |
| Рация | Передача расходует 12 секунд заряда; запас батарейки — 10 минут передач. R заменяет батарейку. |
| Гаечный ключ | Обязателен при установке, снятии и замене колеса. F на креплениях повреждённого бампера расходует один болт. |
| Отвёртка | Требуется для подключения клемм автомобильного аккумулятора. |
| Молоток | F у узла машины выправляет повреждённый бампер. |
| Болты | Расходуются по одному при ремонте креплений ключом. |
| Горелка | Поставить Q, навести прицел, нажать F. Пламя расходует газ, гаснет при опрокидывании, поднятии и пустом баллоне. |
| Кастрюля | Держать канистру воды, навести на кастрюлю, нажать F. Вмещает 2 л. Поставить рядом с горящей горелкой (до 0,8 м), кипячение занимает 20 с. |
| Кружка | Выбрать кружку, F на кастрюле с кипячёной водой или бочке — набрать до 0,35 л. F вне источника — выпить порцию до 0,2 л. |
| Бочка | Вмещает 50 л воды. Заполняется канистрой; вода расходуется при наполнении кружки. F с пустой водяной канистрой набирает воду обратно; Shift+F позволяет долить непустую. |
| Напиток | Содержит 0,5 л; F восстанавливает запас воды персонажа, уменьшая содержимое. |
| Пицца | Четыре порции; F расходует порцию и восстанавливает сытость. |
| Тарелка | Держать тарелку, F на пицце — взять порцию. F вне источника — съесть. Тарелка остаётся. |
| Аптечка | F восстанавливает до 35 здоровья и расходует аптечку. При полном здоровье не тратится. |
| Канистры | Сохраняют объём и тип жидкости. Бензин — в бак, вода — в радиатор или бытовые ёмкости. |
| Ящики | Хранят реальные предметы с их состоянием. |
| Ремкомплект | Восстанавливает бампер, расходуется, требует гаечный ключ. |

Состояние здоровья, сытости и воды отображается в окне инвентаря. Заряд виден на ячейке, другие остатки — при наведении. Показатели персонажа отделены от повреждений машины.

Ограничение ассетов: отдельного сменного газового баллона в найденном наборе нет. Горелка использует свой начальный запас газа; заправка бензином запрещена. Для замены баллона нужна отдельная модель и точка крепления.
